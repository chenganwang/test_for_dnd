# V14 试玩操作

打开 `ActionCRPG.exe`，从「探索」进入准备。选择三人、一个核心及战斗模式，然后出发。模式、核心与菲恩技能槽本局锁定；准备页的修改用于下一局。

- 小队战术：三人实体一起行动，1／2／3 切换当前角色；其余角色执行基础行动。
- 主控连携：一人持续在场，1／2 请求两位队友的招牌技能；队友短暂表现后退场。
- WASD 移动，左键普攻，空格闪避，右键守势；F 当前角色的基础主动，Q 当前角色关键主动。
- Tab 进入战术指挥，选择人物、技能与目标后确认。快捷和战术入口消耗同一资源、CD 与行动，切菜单不会重置。
- 埃文校正在骰后选择 +2；获得复核后可改为整组重掷并强制采用新结果。自然 1／20 保持原规则，D100 不受校正影响。
- 菲恩生长树先施放寄生芽。爆绽在合法目标身上结算自己的剩余跳伤；战术面板会显示剩余跳数及防御前来源伤害。森息与爆绽只能装备一个。守息树可在下一局准备切换。
- E 与场景交互。安全处可保存；继续保持同一局的模式、核心、资源、地图与潮汐记录。

六房旅程沿用四次构筑选择。Boss 的横扫、奔袭、祷歌需要观察预警、走位、柱体和节点。潮汐出现时世界等待现有行动处理完成，落骰后选择接受，或在条件满足时花灵感使用自己的原始骰回声。

演示包不含测试存档。自动测试不等于真人体验；试玩意见可记录所用模式／核心、房间、操作、现象和截图。
