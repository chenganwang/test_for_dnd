# V13 CoreAndAssist 实现合同

CoreAndAssist 已正式接入新探索局。PersistentTrio 用于原三实体快照；没有恢复旧检查点或移除旧路径。

主控由出发快照固定，三个角色数据都保留；V13Physical统一控制物理存在、碰撞、敌方目标、治疗与倒地判断。连携没有常驻战斗实体，不参与常规AI或后台普攻。表现复用原人物模型，只在1.1秒动作演出期启用，结束不删除其技能来源或长期效果。

核心合法位置是CastOrigin与领域距离的唯一锚点。Quote检查技能、目标、费用、墙、射程和Action占用，实际结算重检；不能依据离场同伴历史坐标越墙施法。快捷与战术调用同一命令、付款、CD、行动占用和幂等收据；战术额外资源有独立授权，不重置动作。连携的移动效果不能把核心瞬移到历史同伴位置。

埃文标注/校正、米拉有效操作收益和菲恩所选树各自从actorId数据结算。guard/growth在出发时锁定，所选树只有一被动两主动。旧v12_evan_final和旧树快照保留，新动作明确v13命名。原圣武士核心维持完整规则；其付费连携需要确认一次指挥，不自动授权全力。

V13State保存成员、核心、树、Action/CD、祈愿库存/返还、回声、独立潮汐RNG/历史/地形，以及Boss阶段、登记柱、祷歌节点。旧可空字段省略，保存和克隆使用同一生成器覆盖159 DTO/70容器。未知树/地形/未来格式拒绝重解释，不删未知字段后冒充兼容。

生产入口：Assets/CombatV051/Domain/V13Model.cs、V13Rules.cs、V13Fate.cs、V13Boss.cs、V13Trees.cs及Runtime/BattleWorld.V13*.cs。状态和规则不保存GameObject实例ID。已有角色、技能、资源、存档、场景和.meta身份沿用。
